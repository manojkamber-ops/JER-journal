# Journal of Economic Research (JER) — website

Next.js journal site for the *Journal of Economic Research* (Hanyang University, Seoul; ISSN 1226-4261, eISSN 2713-6418; ABDC B, KCI-listed), styled after the AOM journal layout.

Features: current issue and archive, article pages, an ePub-style reader and PDF/EPUB downloads (generated in the browser), self-issued DOIs that open the paper as a PDF (`#/doi/10.17256/JER.…`), citations, accounts and saved articles, alerts, manuscript submission and contact forms. Papers without a full text show a lock and a "request the full paper from the authors" form.

## Run it locally

Requires Node.js 20+.

```bash
npm install
cp .env.example .env        # fill in the database and Sanity values
npm run dev                 # http://localhost:3000
```

### Database (Neon Postgres via Vercel)

Accounts, sessions and saved articles are stored in the Neon Postgres database `jer-journal-db`, created in
Vercel → Storage and connected to the project (form entries are also copied there). Vercel sets `DATABASE_URL` and
`DATABASE_URL_UNPOOLED` on the project, and every deploy runs `scripts/vercel-build.mjs`, which creates or updates
the tables with `prisma db push` before building. Manuscript files are kept in Sanity when `SANITY_API_WRITE_TOKEN`
is set, and otherwise in the database.

## Where things are

| What | Where |
|---|---|
| Journal info, issues, articles, news, board | `src/data/journal.ts` |
| Full papers / abstract-only papers / reference lists | `src/data/papers/*.ts` (index generated by `node scripts/gen-paper-index.mjs`) |
| Issue editorials | `src/data/editorials.ts` |
| Paper formats | `src/data/paper-spec.ts`, `src/data/article-bodies.ts` |
| Pages and UI | `src/components/journal/` |
| PDF / EPUB generation | `src/lib/pdf.ts`, `src/lib/epub.ts` |
| API routes (auth, saved, alerts, submissions, contact) | `src/app/api/` |

After adding or removing a file in `src/data/papers/`, run `node scripts/gen-paper-index.mjs`.

## Sanity (current-issue papers and form submissions)

Sanity project **Journal of Economic Research** (`imuzzo9u`, organization "Manoj Kamber").

- **Current issue papers** (Vol. 31, No. 2) live in the public dataset `production`. The home page reads them from
  Sanity every 60 seconds (`src/lib/sanity-papers.ts`, `src/data/live-papers.ts`), so a paper added, edited or
  removed in Sanity appears on the website within about a minute, without a redeploy. A paper with no full text is
  shown as abstract + references with a lock and a "request the full paper" form. Earlier issues stay in the
  repository; if Sanity is unreachable, the repository copy of the current issue is shown.
- **Forms** write to the private dataset `forms` from the server: contact messages, manuscript submissions (with the
  uploaded file), full-paper requests, email-alert subscriptions and new reader accounts (never passwords).
  They are also stored in the database.
- **Next issue:** change `studio/current-issue.ts`; the website follows `CURRENT_ISSUE` in `src/data/journal.ts`.

Setup:

1. sanity.io/manage → Journal of Economic Research → API → Tokens → add a token with **Editor** permissions.
2. Put it in `.env` as `SANITY_API_WRITE_TOKEN=…` and in Vercel → Settings → Environment Variables.
3. Import the current issue's papers once: `npm run sanity:push`.
4. Studio: https://jer-journal.sanity.studio (hosted). Locally: `cd studio && npm install && npm run dev` (http://localhost:3333); redeploy with `npm run deploy`. Hosted at
   https://jer-journal.sanity.studio (already deployed). It has two workspaces: "Current issue papers" and "Form submissions".

## Deploying

Vercel builds with `node scripts/vercel-build.mjs` (`vercel.json`): database schema update, then `next build`.
Environment variables in Vercel: `DATABASE_URL` and `DATABASE_URL_UNPOOLED` (set by the Neon integration) and
`SANITY_API_WRITE_TOKEN` (Sanity, added by hand; the project id and datasets have defaults).

All papers, authors and results are realistic **sample content**; DOIs are not registered with Crossref.
