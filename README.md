# Journal of Economic Research (JER) — website

Next.js journal site for the *Journal of Economic Research* (Hanyang University, Seoul; ISSN 1226-4261, eISSN 2713-6418; ABDC B, KCI-listed), styled after the AOM journal layout.

Features: current issue and archive, article pages, an ePub-style reader and PDF/EPUB downloads (generated in the browser), self-issued DOIs that open the paper as a PDF (`#/doi/10.17256/JER.…`), citations, accounts and saved articles, alerts, manuscript submission and contact forms. Papers without a full text show a lock and a "request the full paper from the authors" form.

## Run it locally

Requires Node.js 20+.

```bash
npm install
cp .env.example .env        # DATABASE_URL=file:../db/custom.db
mkdir -p db
npx prisma db push          # creates the local SQLite database
npm run dev                 # http://localhost:3000
```

## Where things are

| What | Where |
|---|---|
| Journal info, issues, articles, news, board | `src/data/journal.ts` |
| Full papers / abstract-only papers / reference lists | `src/data/papers/*.ts` (index generated by `node scripts/gen-paper-index.mjs`) |
| Issue editorials | `src/data/editorials.ts` |
| Paper formats | `src/data/paper-spec.ts`, `src/data/article-bodies.ts` |
| Pages and UI | `src/components/journal/` |
| PDF / EPUB generation | `src/lib/pdf.ts`, `src/lib/epub.ts` |
| API routes (auth, saved, alerts, submissions, contact) | `src/app/api/` |

After adding or removing a file in `src/data/papers/`, run `node scripts/gen-paper-index.mjs`.

## Deploying

The site runs on Vercel, but sign-in, saved articles, alerts, submissions and the contact form use SQLite, which does not persist there. For a live site, switch `prisma/schema.prisma` to a hosted Postgres database and set `DATABASE_URL`.

All papers, authors and results are realistic **sample content**; DOIs are not registered with Crossref.
